# 多版本适配与验证边界

本 skill 提供跨版本工作流程和环境探测，不是一个已在所有版本验证过的通用 DLL。2020 有历史建模记录和本机桥接编译记录；其余版本均需目标机编译、加载及模型验收。当前环境没有其他版本，不得将静态检查写成实机通过。

## 选择目标版本

1. 执行 `scripts/inspect-revit.ps1` 列出安装。指定年份用 `-Year 2024`，自定义安装目录用 `-RevitDirectory 'E:\Apps\Revit 2024'`。年份以 Revit.exe 文件主版本推导并与用户要求校验，不能只看文件夹名。
2. 用户指定版本优先；多版本共存且未指定时，根据已有 RVT 的版本和交付要求选择，仍不明确才询问。没有目标版本时输出缺失状态，不悄悄切换到2020。
3. 在任务目录记录 compatibility.json：目标年份、实际产品版本、API DLL 路径、目标框架、SDK、模板/族库、源码版本、编译结果、Revit加载结果、模型验收结果。未执行项明确写 not-run。

## 运行时与构建

- Revit 2020 的历史方案使用 .NET Framework 和本机 csc。后续版本不能仅替换引用路径就视为兼容。
- 2025 是迁移至现代 .NET 8 的重要分界。2025及之后优先检查该年份 Autodesk SDK 和安装运行时，按实际要求选 TargetFramework，不能假定未来年份永远使用相同 .NET。
- 使用目标年份 SDK/官方文档核实目标框架。旧版采用对应 .NET Framework 的开发包；现代版本采用对应 dotnet SDK，必要时启用 Windows/WPF 支持。缺少目标 API 或 SDK 时报告阻碍，不下载来源不明的 DLL、不用另一年份的 DLL 冒充。
- Bridge 和 Worker 都按目标年份单独编译。构建输出放在独立年份目录；RevitAPI 与 RevitAPIUI 引用来自同一目标安装，设置 CopyLocal/Private=false，不分发 Autodesk DLL。
- 插件清单放入 `%APPDATA%\Autodesk\Revit\Addins\<年份>`，Assembly 指向该年份构建产物。临时插件的加载、请求及清理沿用 api-execution.md。
- assets/IdlingBridge.cs 是待编译的源模板。字节加载在目标运行时的依赖解析与热重载行为仍需测试；若失败，使用明确依赖解析策略或安全重启，不能循环加载。

## Worker 中集中处理的版本差异

将版本差异集中在适配类中，建模规格保持与 API 无关。编译期选目标分支，避免在旧版编译单元直接引用不存在的新类型。

| 功能 | 适配要求 |
| --- | --- |
| 单位 | 旧 DisplayUnitType/UnitType 与新 ForgeTypeId、UnitTypeId、SpecTypeId 接口不同；按目标 SDK 选分支，确认长度和体积转换 |
| 楼板等创建 | 旧 NewFloor 与新版 Floor.Create 等入口按目标 API 可用性选择；洞口、结构属性和标高逐项核验 |
| 参数 | 检查旧枚举与新标识接口、存储类型；避免依赖本地化参数显示名称 |
| ElementId | 新版可能使用更宽整数标识；持久化用不截断的表示，适配 Value/IntegerValue，不盲转 Int32 |
| 材质与明细表 | 核实字段、单位格式和材料层 API，实际导出后比较数量与体积 |
| 视图和标签 | 检查签名、可用性和事务限制，实际导图核验文字与裁剪 |

不将上述表格当成完整 API 差异列表；以目标 SDK 编译诊断及官方迁移说明为准。官方入口：https://www.autodesk.com/developer-network/platform-technologies/revit 。本次在线检索受工具访问错误影响，未完成各年份官方文档复核，目标机适配时需补查。

## 模板、族和 RVT

模板和族库按实际配置发现，旧路径 `ProgramData\Autodesk\RVT <年份>` 只是候选；缺少内容包时允许用户提供路径。不要把2020中文路径作为所有语言和版本的固定值。

RVT/RFA 版本升级先另存副本；不能承诺新版本工程直接另存为旧版原生工程。需要兼容多个年份时优先在约定最低目标版本创建，再分别升级副本并核验；IFC 等交换格式不等于无损旧版 RVT。

## 每个年份的验收

阶段依次为环境发现、目标API编译、插件加载、最小模型冒烟测试、完整题目验收。冒烟测试在新项目中创建代表性的柱梁墙板基础，验证材料、单位、保存重开、明细表和视图导出。未安装目标 Revit 时只能完成可行的前置步骤，不生成虚假的通过标记。
